# cards-steps

Custom **cards** block. Purpose: numbered-options.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: N rows, 1 cell: [h3 title (sup allowed), p text (inline links, em note), p > strong > a CTA (primary button), p disclaimer (small text, optional)]. Numbers 1..N are auto-generated (CSS counter) in a red outlined circle; grey divider between steps; number above content on mobile, left of content on desktop.
