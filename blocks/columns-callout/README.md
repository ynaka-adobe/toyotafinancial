# columns-callout

Custom **columns** block. Purpose: cta-callout.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row, 2 cells: [p > strong title (or h3), p text] | [p > strong > a CTA (primary button)]; white box with red top border and shadow, text left / CTA right on desktop, centred stack on mobile. Option grey: flat #fafafa box with no red top border, shadow or radius, compact bold title (end-of-lease help card).
