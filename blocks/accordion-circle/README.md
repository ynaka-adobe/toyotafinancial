# accordion-circle

Custom **accordion** block. Purpose: faq-accordion.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: N rows, 2 cells: [title text] | [body rich text: p, ul/ol (nested), sup, em disclaimers, links, p > strong > a buttons]; dark grey bold titles, filled red circle +/- icon on the right, grey dividers; all closed on load, opening one closes the others in the same block. Use one block per independent accordion group.
