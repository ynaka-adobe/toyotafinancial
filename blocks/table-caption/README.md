# table-caption

Custom **table** block. Purpose: captioned-data-table.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: 1 merged cell [h3 caption, p] rendered as a dark caption box; row 2: header cells (e.g. Rating | FICO Score | Description); rows 3..n: data cells, first column bold row label; light row dividers and outer border.
