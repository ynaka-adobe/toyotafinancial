# video-poster

Custom **video** block. Purpose: click-to-play-video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: link to the MP4 URL (absolute, hosted on toyotafinancial.com); row 2: poster picture. Poster swaps to an inline HTML5 player with controls on click; centred at 8/12 width on desktop, full width on mobile.
