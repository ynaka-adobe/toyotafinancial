# cards-video

Custom **cards** block. Purpose: video-tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: N rows, 2 cells: [poster picture] | [h3 title, p description, p > a MP4 URL (absolute https://www.toyotafinancial.com/content/dam/.../*.mp4)]; white shadowed tiles with centred title, red rule, description and the poster (play icon) at the bottom; 2 per row from 900px, 1 on mobile; clicking the poster opens a modal dialog that plays the MP4 with controls, closing pauses and removes it.

## Supported variations

No variations.
